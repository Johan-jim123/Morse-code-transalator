# Morse-code-transalator
A simple morse code transalator , that also beeps. 
It takes users input and uses my  mapping table to convert it into morse and later creates beeps based on the dots and dashes

## how to use it
STEP_1:   go to the dist folder and oepen uri.text
STEP_2: Copy the text in it and paste it into ur search area
STEP_3: You will be able to see the screen
<img width="438" height="443" alt="image" src="https://github.com/user-attachments/assets/7eb091e2-4356-4a61-9a48-0a4546d69fbb" />
STEP_4: Write your text ( hobbies , favorate flavour of icecream,etc) and click transalate.
STEP_5: Now you can see the morse code text and finally communicate with you alien friend

## how it works
It takes input from the user . Uses my mapping table to map each letter to a combination of morse code .
It changes thee letter to their respective combination and print it in the output textarea .
Then it uses the dots and dashes in the output and using the The Web Audio Synthesizer to change it into beeps
